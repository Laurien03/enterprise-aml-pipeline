AML-Enterprise: Transaction Monitoring & Risk Scoring System 

An end-to-end anti-money laundering monitoring system that combines anomaly detection, risk scoring, machine learning classification, and explainability techniques to assist AML analysts, risk analysts, and compliance teams in identifying and reporting suspicious financial activity. 

  

Executive Summary 

ML-Enterprise is an end-to-end anti-money-laundering transaction monitoring system inspired by regulatory deficiencies identified within the    Canadian banking sector. The project aims to assist compliance teams in detecting potentially suspicious transactions, prioritizing high-risk cases for investigation, and supporting regulatory reporting workflows. By combining transaction analysis, anomaly detection, risk scoring, and automated alert generation, the system demonstrates how machine learning can strengthen AML monitoring processes while reducing the risk of missed suspicious activity. 

  

Problem Statement 

Financial institutions process millions of transactions daily. Identifying suspicious activity manually is difficult, time-consuming, and subject to operational limitations. Failure to detect and report suspicious transactions can expose institutions to regulatory penalties, reputational damage, and financial losses. The goal of this project is to improve the identification of potentially suspicious transactions by supporting compliance teams with automated transaction monitoring and risk assessment capabilities. 

  

Business Context 

In 2023, FINTRAC imposed a multi-million-dollar administrative monetary penalty on RBC after identifying deficiencies in aspects of the bank's anti-money laundering compliance program. The enforcement action highlighted the operational risks associated with monitoring large volumes of financial transactions while maintaining regulatory compliance. As transaction volumes continue to increase, financial institutions face growing pressure to improve the effectiveness of transaction monitoring systems and ensure suspicious activities are identified, investigated, and reported appropriately. This project explores how machine learning techniques can support these objectives.
